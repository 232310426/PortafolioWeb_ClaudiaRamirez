## Descripción General

Este portafolio reúne los proyectos desarrollados durante la asignatura de Desarrollo de Aplicaciones Web. Cada proyecto permitió aplicar conocimientos relacionados con el diseño y desarrollo de aplicaciones web, el manejo de bases de datos, el consumo de servicios web, la administración de contenido y el uso de herramientas de control de versiones.

Durante el desarrollo de estas actividades se trabajó con diferentes tecnologías y metodologías que fortalecieron las habilidades de programación, organización de proyectos y resolución de problemas.

### Tecnologías utilizadas durante el curso

- PHP
- HTML5
- CSS3
- MySQL
- phpMyAdmin
- WordPress
- REST API
- cURL
- Git
- GitHub
- XAMPP
- Moodle

### Competencias desarrolladas

- Desarrollo de aplicaciones web dinámicas.
- Consumo de servicios web mediante APIs REST.
- Manejo de bases de datos relacionales.
- Implementación de operaciones CRUD.
- Uso de control de versiones con Git y GitHub.
- Organización de proyectos utilizando estructuras MVC.
- Gestión de usuarios y autenticación.
- Creación y administración de sitios web con WordPress.
- Documentación y presentación de proyectos tecnológicos.

## Proyectos Incluidos

### Proyecto 1. Sistema de Gestión de Citas

Aplicación web desarrollada en PHP y MySQL que permite a los usuarios registrarse, iniciar sesión y administrar citas mediante operaciones CRUD. Se implementó una estructura MVC, manejo de sesiones y consultas seguras utilizando PDO.

**Tecnologías utilizadas:**
- PHP
- MySQL
- phpMyAdmin
- HTML
- CSS
- XAMPP

---

### Proyecto 2. Consumo de API REST con The Dog API

Aplicación desarrollada en PHP utilizando cURL para consumir servicios REST de The Dog API. Permite obtener información sobre razas de perros y mostrar imágenes dinámicamente desde una API externa.

**Tecnologías utilizadas:**
- PHP
- REST API
- cURL
- JSON
- HTML

---

### Proyecto 3. Sitio Web Portafolio en WordPress

Sitio web desarrollado en WordPress con páginas informativas, menú de navegación, personalización de tema y publicación de proyectos realizados durante el curso.

**Tecnologías utilizadas:**
- WordPress
- HTML
- CSS
- Plugins de WordPress
